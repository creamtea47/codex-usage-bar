# CodexUsageBar v0.8.1

## 简体中文

- Plus 挂件同时显示 5 小时和周额度的建议剩余，历史样本足够时可查看耗尽预测。趋势页可在同一历史范围内切换额度窗口，查看实测线、建议线、区间消耗和周期详情。
- 新增官方浏览器登录导入，支持取消登录和更新已有账号凭据。文件导入继续可用，切换本机 Codex 仍由「应用到 Codex」控制。
- 在「设置 → 显示」可立即进入轻量模式，或在两个窗口都收起后延时进入。后台继续刷新、记录历史并发送通知。托盘和设置显示进入前后的实测内存及统计范围。
- macOS 在系统代理或网络变化后重新建立请求。通知可分别提醒重置卡到账、额外额度到账以及连接断开／恢复。升级保留已保存的通知偏好。
- 重构了窗口入口、账号订阅、历史与接续模块。修复账号事件监听乱序注册时的清理问题，并增加旧数据重新打开、迟到响应和账号隔离回归测试。

## English

- The Plus widget shows pacing targets for five-hour and weekly quotas, alongside exhaustion forecasts when enough samples are available. Compare either window over the same history range, including target lines, range consumption and cycle details.
- Accounts can be imported through official browser sign-in or from a file. Signing in again refreshes the managed credentials. Applying an account to the local Codex installation remains a separate action.
- Display settings can release both WebViews immediately or after both windows have been hidden for a configurable delay. Background refresh, history and notifications continue. The tray and settings show the measured memory change and its scope.
- On macOS, changing a proxy or network triggers new usage requests. Alerts cover reset credits, extra credits and connection loss or recovery. Upgrading preserves saved notification choices.
- Window entry points, account subscriptions, history and continuation now have separate owners. This release fixes out-of-order listener cleanup and adds coverage for persisted data, late responses and account isolation.

## 安装与更新 / Installation

Windows 提供 x64 和 ARM64 安装程序，macOS 提供 Intel 和 Apple silicon DMG。应用内更新使用 Tauri 签名校验。macOS DMG 未经 Apple 公证。Windows and macOS installers are provided for both architectures. In-app updates verify Tauri signatures. The macOS DMGs are not Apple-notarized.
