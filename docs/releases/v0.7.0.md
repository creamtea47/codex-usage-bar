# CodexUsageBar v0.7.0

本版加入多账号管理、范围与周期用量明细，并改进模型测试和紧凑主窗。

- **多账号**：批量导入 `auth.json` 托管副本，各账号独立监测、刷新、预测、通知和自动接续；账号卡片展示身份、套餐、额度和订阅记录。
- **查看与登录分开**：主窗标题栏和设置左下角切换查看账号；Codex 登录来源按磁盘文件识别。“应用到 Codex”和恢复凭证仍是独立操作，保留现有 provider 配置。
- **范围与周期**：图表点选两点统计经过时间和跨重置累计消耗；每个周期提供汇总及分页采样，注明部分覆盖和历史精度。
- **预测**：趋势与周期列表显示距耗尽时长及比重置提前多久。主窗保留简短建议，完整预测可悬浮或键盘聚焦查看。
- **模型与回复**：每账号支持自动选择、模型列表和手填 ID，移除固定旧模型回退；保存最近自动/手动请求的模型、回复、耗时、HTTP 状态及脱敏错误。结果不确定时不自动补发。
- **重置卡有效期**：区分持有数量与当前可用数量，展示最近到期时间及逐张明细；只读查询、每账号缓存 5 分钟，失败可重试，不兑换重置卡。
- **紧凑主窗**：账号按钮位于刷新与设置之间，自动高度恢复紧凑布局，手动尺寸继续保留。

升级保留已有设置、历史盐值和账号分区。凭据仅由本地 Rust 后端处理；完整账号资料仅向设置窗口开放。新导入账号默认关闭自动接续，真实模型测试仍需明确确认。

Windows x64 / ARM64 与 macOS Intel / Apple silicon 均提供安装包。应用内更新包由 Tauri 签名验证；macOS DMG 尚未经过 Apple 公证。v0.2.5 及更早版本需先手动安装新版。

## English

- Manage multiple local credential copies with independent monitoring, token refresh, notifications, continuation settings and model choices.
- Switch the viewed account from the compact title bar or Settings sidebar. Codex credential application remains a separate Windows file-store operation and preserves provider configuration.
- Select chart ranges across resets, inspect cycle summaries and retained samples, and compare estimated exhaustion with the reset deadline.
- Inspect retained automatic/manual model responses, timing and sanitized failures; uncertain delivery is not replayed automatically.
- See held versus currently usable reset credits and each credit's expiration through a read-only, cached query.
- Keep short forecasts in the compact main window and full forecast details in accessible tooltips.
